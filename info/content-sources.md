# Content Sources, Standards & Bibliography

## 1. Primary Standards & Documents
1. **ISO 11088:2018 / ISO 11088:2024:**
   - *Title:* Assembly, adjustment and inspection of the ski-binding-boot (S-B-B) system for alpine skiing.
   - *Governing Body:* International Organization for Standardization (ISO).
   - *Key Tables Used:* Table 1 (Skier classification & weight/height codes), Table 2 (Indicator settings by Skier Code and Boot Sole Length).

2. **ASTM F939:**
   - *Title:* Standard Practice for Selection of Release Torque Values for Alpine Ski Bindings.
   - *Organization:* ASTM International.

---

## 2. Official Manufacturer Technical Manuals
- **Marker Ski Bindings Technical Manual:** Binding mounting, testing, and indicator setting tables.
- **Salomon / Atomic Alpine Technical Manual:** ISO 11088 compliance and technician adjustment guidelines.
- **Look / Rossignol / Dynastar Tech Manual:** Dual WTR / GripWalk compatibility & DIN calibration procedures.
- **Tyrolia / Head Bindings Technical Manual:** Release torque measurement and inspection criteria.
